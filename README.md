# DEADSELL

*Dead Cells*의 핵심 루프(빠른 근접 전투, 수제 방 템플릿 기반 절차 생성 맵, 영구 사망 + 메타 성장,
바이옴 → 쉼터 → 바이옴 → 보스)를 모바일 웹으로 재현한 2D 로그라이트입니다.
메커니즘은 원작을 충실히 따르고, **이름·캐릭터·아트는 전부 오리지널**이며 **등장인물은 모두 여성**입니다.

- **플레이**: Claude 아티팩트 링크(공유 메뉴에서 지정한 사람만 접근). 빌드 전용 저장소 `deadsell-play`는 비공개이며,
  깃허브 Pro 이상에서 Pages를 켜면 https://rockyhong-a11y.github.io/deadsell-play/ 로 다시 열 수 있습니다.
- 휴대폰 브라우저 가로 화면 권장. PC에서는 키보드로도 플레이 가능.

## 게임 구성
| 순서 | 레벨 | 내용 |
|---|---|---|
| 1 | 가라앉은 감옥 | 절차 생성 맵. 구울·여간수·궁수·폭탄마 + 변종, **중간 보스 1명**(수녀원장 / 거미 여왕 중 시드로 결정). 시작 지점 옆에 **보관함** |
| 2 | 쉼터 | 연금술사 모르웬(셀로 영구 강화 구매), 회복 샘, **재봉사 셀마**(유니크 조합), **보관함**, **누더기 더미**(골렘 제작). 들어서면 들고 있던 시체 조각이 셀마에게 맡겨짐 |
| 3 | 달빛 성벽 | 절차 생성 맵. 창기병·하피 등 + 변종, **중간 보스 1명**(발키리 기사단장 / 달의 마녀 중 시드로 결정) |
| 4 | 쉼터 | 위와 동일 |
| 5 | 사슬의 종탑 | 보스 「강철 여교도관」 (2페이즈) |

사망하면 1번부터 새 시드로 다시 시작합니다. 쉼터에서 쓰지 않은 셀과 쉼터에 맡기지 못한 시체 조각은 사망 시 사라집니다. 강철 여교도관을 쓰러뜨리면 **다음 회차**가 시작됩니다(엔딩 없음).

## 시체 조각 · 회차 (DEAD + SELL)
가라앉은 감옥은 시체 시장입니다. 「그들은 죽은 자를 팔았다.」 처형된 신더의 영혼은 빈 몸으로 걸어 나와, 쓰러뜨린 자들에게서 떨어진 **시체 조각**을 모읍니다.
자세한 규칙은 `docs/CONTENT3.md`, `docs/CONTENT4.md`, 수치는 `src/game/rules.ts`(`CORPSE`, `LOOP`, `GOLEM`, `SPRINT`, `STASH`, `GRADES`, `CRAFT`)에 있습니다.

| 항목 | 규칙 |
|---|---|
| 획득 | 처치 시 시체 조각 드롭: 일반 1 · 정예 3 · 중간 보스 8 · 강철 여교도관 12 (한 바퀴 전부 처치 ≈ 100) |
| 맡기기 | 들고 있는 조각은 사망 시 사라짐. **쉼터에 들어서면 전부 셀마에게 맡겨져**(`save.pieces`, 영구) 조합·골렘에 쓰임. 보스 처치 시에도 맡겨짐 |
| 회차 | 강철 여교도관 처치 = 승리 → 다음 회차(타이틀에 `N회차`). 승리 화면에 `맡긴 시체 조각 +N`, `종탑의 파편 +1`, `다음 회차: N`. 엔딩·몸 100조각 완성은 없음 |
| 종탑의 파편 | 여교도관을 쓰러뜨릴 때마다 1개, 그 회차가 새겨져 영구 보관(`save.shards`). 높은 등급 유니크의 재료 |
| 누더기 골렘 | 쉼터의 누더기 더미에서 맡긴 조각 **30개**(회차마다 +15)로 제작. 이번 런 동안 따라다니며 내려찍기로 싸움, 쉼터마다 완전 회복, 쓰러지면 다음 쉼터에서 다시 제작 |
| 회차(2회차~) | 적·중간 보스·보스 체력 +30% / 피해 +20% (회차마다), 정예 확률 +5%p, 골렘 비용·능력치 상승. 5회차부터는 고정 |

## 질주 (대시)
데드셀처럼 **오래 달리면 가속**합니다. 같은 방향으로 땅에서 **0.9초** 달리면 질주 상태가 되어 속도 ×1.6(150 → 240px/s)이 되고, 전용 모션(몸을 숙이고 머플러가 수평으로 날림)에
청록색 **잔상**, 발이 닿을 때마다 먼지, 뒤로 흐르는 속도선이 붙습니다.

- 멈추기(0.12초 넘게 방향을 놓음) · 방향 전환 · 앞의 벽 · 공격 / 스킬 / 구르기 / 내려찍기 / 모서리 잡기 / 피격이 질주를 끝내고 달리기 시간이 다시 시작됩니다.
- 질주 중 점프하면 착지 전까지(또는 방향을 바꿀 때까지) 가로 속도를 유지합니다.
- **광란 질주**: 적을 2.5초 간격 안에 **3번 연속 처치**하면 5초 동안 모든 이동이 즉시 질주가 됩니다(붉은 잔상 + 불씨 오라, `광란 질주!` 표시). 처치할 때마다 다시 5초로 채워집니다.

## 보관함
쉼터와 가라앉은 감옥 시작 지점의 **관 모양 상자**에서 엽니다. 24칸, **영구 보관**(죽어도 유지).
- 위쪽에 장착 중인 4칸(무기 2 · 스킬 2), 아래에 24칸 격자와 선택한 아이템의 카드(이름 · 등급 · 티어 · 접사 · 효과).
- `장착`: 같은 종류의 빈 칸에 장착, 두 칸이 다 차 있으면 바꿀 칸을 고름(바뀐 장비는 그 자리로 보관). `맡기기`: 장착 중인 장비를 보관(주무기 칸이 비어도 됨). `분해`: 한 번 더 눌러 확정, 시체 조각으로 환산(일반 `1 + (티어 − 1) + 접사 1`, 유니크는 등급별 5~80).
- 바닥의 장비를 주울 때 칸이 모두 차 있으면 **`보관함으로 보내기 · n/24`** 를 고를 수 있습니다. 중간 보스가 떨어뜨린 장비에는 표시(`mb`)가 붙어 조합 재료로 따로 쓰입니다.
- 조작: 터치(칸·버튼 탭) · 키보드(방향키, Enter, `X` = 분해, Esc) · 게임패드(십자키/스틱, A, `Y` = 분해, B).

## 조합 (유니크 제작)
유니크는 드롭·상자·상점에 나오지 않고 **재봉사 셀마**(`조합`)에게서만 만듭니다. 등급 **C B A S SS SSS**마다 5종, 같은 유니크를 몇 번이든 만들 수 있고 결과물은 보관함으로 들어갑니다(접사 없음).
재료는 보관함에서 값싼 것부터(티어 낮은 것 → 접사 없는 것 → 중간 보스 장비가 아닌 것 → 오래된 것) 자동으로 쓰이며, 쓰일 칸이 확정 전에 강조됩니다.

| 등급 | 보관함 재료 | 추가 | 맡긴 조각 | 결과 티어 |
|---|---|---|---|---|
| C | 아무 아이템 3개(유니크 제외) | — | 10 | 1 |
| B | 접사가 붙은 아이템 3개 | — | 20 | 2 |
| A | 티어 2 이상 2개 + 중간 보스 아이템 1개 | — | 35 | 2 |
| S | A급 유니크 1 + 중간 보스 아이템 2 | 종탑의 파편 1(어느 회차든) | 50 | 3 |
| SS | S급 유니크 1 + A급 유니크 1 | 종탑의 파편 2(2회차 이상) | 80 | 3 |
| SSS | SS급 유니크 1 + S급 유니크 1 | 종탑의 파편 3(3회차 이상) | 120 | 4 |

한 판(감옥 + 쉼터 + 성벽)에서 장비 3~6개와 시체 조각 약 70개가 나오므로, 1~2스테이지를 한두 번 반복하면 C급 유니크 1개를 얻습니다. 높은 등급은 회차가 올라야 합니다.
등급 뱃지(`[S]`)는 아이템 카드·보관함·조합 목록·HUD 무기 아이콘(모서리 글자)·도감에 표시됩니다.

**유니크 (C·B 등급 10종)** (데드셀의 무기 계열·전설 아이템 체계 참고, 기존 무기 모션을 재사용. 등급: C = 뼈 도살검·재봉 바늘·관 뚜껑·뼈 가시·사슬 갈고리, B = 나머지 다섯)

| 골수 활 | 활 | 완전히 당긴 화살이 모든 적을 관통 |

## 일반 무기 · 스킬 (22종 추가)
데드셀의 무기 계열(검·창·단검·대형·활·방패·채찍·투척·지팡이)과 스킬 계열(수류탄·설치형·이동기)을 오리지널 이름으로 풀었습니다. 수치는 `src/game/player/weapons.ts`, `src/game/player/skills.ts`에 있습니다.
**청사진**: ★ 표시가 없는 항목은 쉼터의 연금술사에게서 셀(20~40)로 청사진을 사야 드롭 목록(상자·제단·정예·중간 보스)에 들어옵니다. ★ 4종은 처음부터 드롭됩니다(옛 세이브도 그대로 열림).

## 적 (30종)
기본 6종 + 변종 24종(변종마다 전용 스프라이트 시트와 행동 변화가 있음). 변종은 진행도(깊이)가 깊어질수록 더 자주,
"후반" 표시가 붙은 것은 레벨 40% 지점부터 나옵니다. 정예(elite)는 능력치·오라만 강화되고 크기는 그대로입니다.
감옥 = 가라앉은 감옥, 성벽 = 달빛 성벽.

**구울 (감옥 중심 · 근접)**
- 구울 — 기본 근접 적
- 역병 구울 — 느리다. 죽으면 독구름(반경 40px, 3초, 초당 4)을 남김. 감옥
- 광란 구울 — 빠르고 2연타, 체력 70%. 감옥 후반·성벽
- 족쇄 구울 — 쇠사슬 철퇴 휘두르기(사거리 ×1.7, 피해 ×1.4, 강한 넉백). 감옥
- 망령 구울 — 플레이어 뒤로 순간이동(90px 이내)해 공격, 넉백 무시, 체력 80%. 감옥 후반·성벽

- 수석 간수 — 메이스 내려찍기가 바닥 충격파(점프로 회피)를 보냄. 감옥 후반·성벽
- 횃불 간수 — 공격에 점화(3초 화상), 횃불 빛을 들고 다님. 감옥
- 창 간수 — 창 찌르기(사거리 ×1.6). 감옥·성벽
- 사슬 간수 — 사슬 갈고리(180px)로 플레이어를 끌어당긴 뒤 강타, 방패 없음. 감옥 후반·성벽

- 궁수 — 기본 화살

- 석궁수 — 1.2초 조준 후 관통 볼트(피해 ×1.8, 반사 불가). 감옥 후반·성벽

- 서리 폭탄마 — 폭탄이 2초간 빙결(피해 ×0.6). 성벽

모든 공격은 예비동작(자세·번쩍임·바닥 표시) 뒤에 들어옵니다. 넉백 없음, 패링·기절만 잠깐 끊을 수 있습니다.
체력 약 650(감옥) / 900(성벽) × 난이도 보정.
**처치 보상(공통)**: 무기 1개 + 스킬 1개(티어 +1, 접사 보장) + 셀 10–15 + 골드 60–100.

## 조작
**설정 > 조작**(타이틀 우상단 `설정` 버튼, 또는 일시정지 메뉴의 `설정`)에서 세 가지 방식 중 고를 수 있습니다.
어느 방식이든 **키보드는 항상 함께 동작**하고, **게임패드는 연결되어 있으면 방식과 관계없이** 입력을 받습니다.

### 1. 터치 제스처 (기본, 버튼 UI 최소화)
| 입력 | 동작 |
|---|---|
| 화면 왼쪽 드래그 | 이동 (손가락 위치에 투명 조이스틱) |
| 오른쪽 탭 | 주무기 공격 (연타 시 콤보) |
| 오른쪽 위로 스와이프 | 점프 (공중에서 한 번 더: 2단 점프, 길게 유지 시 최대 높이) |
| 오른쪽 좌/우 스와이프 | 구르기 (무적, 적 통과) |
| 오른쪽 아래로 스와이프 | 공중: 내려찍기 / 발판 위: 아래로 내려가기 |
| 오른쪽 길게 누르기 | 보조 무기 (활 조준·발사, 방패 막기·패링) |
| 좌상단 플라스크 아이콘 | 회복 |
| 우하단 스킬 아이콘 | 스킬 1/2 |
| 오브젝트 위 말풍선 탭 | 상호작용 (상자, 아이템, 문, NPC) |
| 우상단 미니맵 탭 | 전체 지도 |

### 2. 가상 버튼
화면 왼쪽에 방향키(← → ↓, 손가락을 밀어 방향 전환), 오른쪽에 `공격` `점프`(누르고 있으면 높이 점프)
`구르기`(누르고 있는 방향, 없으면 바라보는 방향) `보조`(누르고 있는 동안 활 조준·방패)와 장착한 스킬 버튼(아이콘 + 쿨다운)이 표시됩니다.
손가락마다 처음 누른 버튼을 따라가므로 **→ + 점프 + 공격을 동시에** 누를 수 있습니다.
`버튼 크기`(작게/보통/크게)와 `투명도`(연하게/보통/진하게)를 바꿀 수 있고, HUD(체력·미니맵·무기 아이콘)와 겹치지 않게 배치됩니다.
플라스크, 상호작용 말풍선, 미니맵, 일시정지는 그대로 화면을 터치합니다. 이 모드에서는 제스처 인식이 꺼집니다.

### 3. 게임패드 (Gamepad API, 표준 배치 / Xbox 이름)
패드를 연결하고 아무 버튼이나 누르면 `게임패드 연결됨: <이름>`이 표시됩니다. 설정에서 이 모드를 고르면 터치 컨트롤·힌트가 숨겨지고
연결된 패드 이름과 상태(`연결됨` / `게임패드를 연결하고 아무 버튼이나 누르세요`)가 보입니다.

| 동작 | 기본 버튼 | 동작 | 기본 버튼 |
|---|---|---|---|
| 점프 (길게 = 높이) | A | 상호작용 | RB |
| 구르기 | B | 스킬 1 | LT |
| 공격 | X | 스킬 2 | RT |
| 보조 무기 | Y | 지도 | Back(뒤로) |
| 회복 | LB | 일시정지 | Start(시작) |

이동은 왼쪽 스틱(데드존 0.25) 또는 십자키, 스틱/십자키 아래는 `아래`(내려찍기 · 발판 내려가기)입니다.
**모든 메뉴**(타이틀, 일시정지, 설정, 도감, 선택창, 연금술사, 지도, 사망/승리 화면)는 십자키/스틱으로 이동, **A 확인, B 뒤로**로 조작합니다
(메뉴에서는 매핑과 관계없이 항상 물리 A/B 버튼, 도감의 탭 전환은 항상 물리 LB/RB).
**버튼 매핑 변경**: 설정 > 조작 > 게임패드에서 동작을 고르고(`버튼을 누르세요…`) 원하는 버튼을 누르면 할당됩니다.
이미 쓰는 버튼이면 두 동작이 서로 교체되고, `기본값 복원`으로 되돌릴 수 있습니다.

### 키보드 (항상 사용 가능)
A/D 이동, W·Space 점프, J 공격, K 보조, L·Shift 구르기, S 아래, Q/E 스킬, R 회복, F 상호작용, M 지도, Esc 일시정지.
메뉴: 방향키/WASD 이동, Enter·J·Space 확인, Esc 뒤로. 타이틀에서 Esc = 설정, 방향키로 시작 · 도감 · 설정을 고릅니다.

## 설정
`설정`은 **조작 / 그래픽 / 사운드** 탭으로 나뉘며, 터치·키보드·게임패드로 조작합니다. 바꾼 값은 **즉시 적용되고 자동 저장**됩니다.
조작 탭에는 선택한 방식의 미리보기(제스처 애니메이션 / 버튼 배치 / 패드 매핑 표)가 나옵니다.

### 그래픽
| 항목 | 선택지 |
|---|---|
| 필터 | **선명(픽셀)** (기본) · **부드럽게** (쌍선형 확대) · **CRT** (주사선 + 비네팅 + 약한 RGB 마스크/잔광) · **LCD** (픽셀 격자) · **선명한 색감** (채도·대비↑) · **흑백** |
| 해상도 | 월드 버퍼 높이 **288**(가까이) / **360**(기본) / **432**(넓게 보임). HUD·글자 크기는 해상도와 무관하게 그대로 |
| 화면 맞춤 | **화면 채우기** (기본) · **정수 배율** (픽셀 단위 정확한 배율 + 검은 여백) |
| 화질 | **고화질** (devicePixelRatio 최대 2) · **절전** (DPR 1, 배터리·성능) |

필터는 게임 화면(월드)에만 적용되고 HUD·메뉴 글자는 항상 선명하게 위 레이어에 그려집니다. 색 필터는 CSS `filter`라 iOS Safari에서도 동작합니다.

## 도감
게임의 모든 **무기·스킬·적·보스·아이템**을 한 화면에서 볼 수 있습니다(숨겨진 `???` 항목 없음).
**타이틀 우상단 `도감` 버튼**(설정 왼쪽)이나 **일시정지 메뉴의 `도감`**으로 엽니다. 일시정지 메뉴에서 열어도 판은 멈춘 채로 유지되고,
닫으면(닫기·Esc·B) 일시정지 메뉴로 돌아옵니다. 타이틀에서는 타이틀 위에 덮이는 화면입니다.

| 탭 | 내용 |
|---|---|
| 무기 (39, 유니크 18 포함) | 아이콘, 색(잔혹/전술/생존)으로 칠한 이름, 설명, 콤보(타수 × 타당 피해), 속도, 사거리, 치명타 규칙, 특수 효과(출혈·기절·패링…), 성장 방식, 붙을 수 있는 접사. 미리보기: 주인공이 콤보 모션을 순서대로 재생(활은 조준 → 발사 + 화살, 방패는 막기 → 패링) |
| 스킬 (24, 유니크 12 포함) | 재사용 시간, 시전 시간, 피해·범위·지속, 접사. 미리보기: 주인공의 `throw`/`deploy` + 수류탄 궤적·폭발 범위 / 포탑 / 덫 (유니크는 등급 묶음 아래에 고유 효과·조합 재료 줄이 붙음) |

| 보스 (5) | 중간 보스 4명 + 강철 여교도관: 체력, 바이옴, 공격 목록(공격마다 한 줄, 피해 포함), 보상(중간 보스 = 무기 1 + 스킬 1 + 셀/골드). 미리보기: 시트의 모든 동작, 미리보기 칸에 맞춰 축소 |

미리보기 칸의 스프라이트는 **정수 배율**(화면 픽셀 단위로 딱 떨어지는 배율, 칸보다 큰 보스만 축소)로 어두운 판 위에 그려지며,
동작은 저절로 넘어갑니다. 아래 방식으로 바로 다음 동작으로 넘길 수도 있습니다.

| | 탭 | 항목 | 동작 넘기기 | 스크롤 | 닫기 |
|---|---|---|---|---|---|
| 터치 | 탭 이름 터치 | 목록 터치 | 미리보기 터치 | 목록·설명을 드래그/튕기기(관성) | `닫기` |
| 키보드 | ← → 또는 Q / E | ↑ ↓ (꾹 누르면 반복) | Enter · J · Space | 목록: 선택을 따라감 · 마우스 휠 / 설명: PgUp · PgDn · Home · End, Shift+↑↓(두 줄씩) | Esc |
| 게임패드 | LB / RB (또는 십자키 ← →) | 십자키/스틱 ↑ ↓ | A | 목록: 선택을 따라감 / 설명: 오른쪽 스틱 ↑ ↓ | B (또는 Start) |

설명이 칸보다 길면(최종 보스처럼 줄이 많은 항목, 좁은 화면) 설명 아래쪽이 흐려지며 `▼`가 나오고, 스크롤하면 `▲`도 나옵니다.
키보드·게임패드 안내줄에는 그때만 설명 스크롤 키(`PgUp/PgDn` · `R스틱`)가 함께 표시됩니다.

숫자와 이름은 게임 자체의 표(`items.ts`, `player/weapons.ts`, `player/skills.ts`, `enemies/variants.ts`, 중간 보스·보스 상수,
`meta/progression.ts`)에서 만들어지므로 밸런스를 바꾸면 도감도 같이 바뀝니다. 여러 곳에서 쓰이는 수치(치명타 배율, 접사 수치, 티어/정예 배율,
드롭량 등)는 `src/game/rules.ts`로 모았습니다. 코드는 `src/game/ui/codex.ts`(화면), `src/game/ui/codexData.ts`(항목 목록), 시험은
`tests/codex.test.ts`, `e2e/codex.spec.ts`입니다.

## QA용 URL 플래그
`?seed=123`(시드 고정) · `?level=passage|ramparts|boss`(해당 레벨로 바로 이동) · `?god=1`(무적) · `?mute=1` · `?debug=2`(히트박스 표시)

브라우저 콘솔의 `window.__ds`: `start(seed)`, `gotoLevel('boss')`, `god()`, `teleport(x,y)`, `killAll()`, `give('spear', 0)`, `info()`,
`spawn('ghoul_plague')`(30종 아무 적이나 플레이어 앞에 소환), `gotoMiniboss()`(현재 레벨의 중간 보스 방 입구로 이동. 중간 보스가 있는 바이옴 레벨이 아니면 감옥 레벨을 먼저 로드하므로 몇 프레임 뒤 한 번 더 호출),
`pieces(n)`(들고 있는 시체 조각), `bank(n)`(맡긴 조각), `shards(1, 2, 3)`(종탑의 파편), `loop(n)`(회차), `golem()`(골렘 소환), `stash()` / `stashAdd(id, tier?, affix?, mb?)`(보관함), `drop(id, tier?, affix?, mb?)`(바닥에 아이템),
`craft('C', 'bone_cleaver')`(조합), `sprint()`(광란 질주 시작), `give('reaper_scythe', 0)`(유니크도 가능).

## 알려진 이슈
- `window.__ds` 디버그 훅과 `?god=1`이 배포 빌드에 포함되어 있음 (QA용, 정식 공개 전 제거 권장)
- 844×390 등 일부 해상도에서 비정수 배율 스케일링으로 픽셀 폭이 고르지 않음 (설정 > 그래픽 > 정수 배율로 해결, 단 DPR 3 기기에서는 캔버스가 DPR 2로 제한되어 완전한 픽셀 퍼펙트는 아님)
- 게임패드·가상 버튼은 실제 기기에서의 손맛(버튼 위치, 스틱 느낌, 진동 없음)을 자동 테스트로 확인할 수 없음 (가짜 `navigator.getGamepads`와 CDP 터치로만 검증)
- 노치 기기 safe-area, 실제 사운드 청취는 실기기에서 확인 필요 (헤드리스 환경에서는 오류 없음만 확인)
- 중간 보스 방은 열린 통로라 보스를 무시하고 지나갈 수 있음(문이 닫히는 연출 없음). 변종 중 까마귀 하피·그림자 궁수는 어두운 배경에서 대비가 낮음
- 유니크 무기는 같은 계열 기존 무기의 주인공 모션을 그대로 쓰므로 손에 든 무기 모양은 기본 무기(예: 사신의 낫 = 전쟁 망치, 장례 종 = 망치)로 보임. 아이콘·카드·베기 색만 다름. 새 유니크의 투사체·소환물(칼날, 혼불, 번개, 독 안개, 구슬, 사슬, 바늘비, 큰 종)은 스프라이트 없이 코드로 그림
- 게임 제목 "DEADSELL"은 저장소 이름을 사용한 가제이며 상표 "Dead Cells"와 유사하므로 정식 공개 전 검토 필요
