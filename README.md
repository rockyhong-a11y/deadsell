# DEADSELL

*Dead Cells*의 핵심 루프(빠른 근접 전투, 수제 방 템플릿 기반 절차 생성 맵, 영구 사망 + 메타 성장,
바이옴 → 통로 → 바이옴 → 보스)를 모바일 웹으로 재현한 2D 로그라이트입니다.
메커니즘은 원작을 충실히 따르고, **이름·캐릭터·아트는 전부 오리지널**이며 **등장인물은 모두 여성**입니다.

- **플레이**: Claude 아티팩트 링크(공유 메뉴에서 지정한 사람만 접근). 빌드 전용 저장소 `deadsell-play`는 비공개이며,
  깃허브 Pro 이상에서 Pages를 켜면 https://rockyhong-a11y.github.io/deadsell-play/ 로 다시 열 수 있습니다.
- 휴대폰 브라우저 가로 화면 권장. PC에서는 키보드로도 플레이 가능.

## 게임 구성
| 순서 | 레벨 | 내용 |
|---|---|---|
| 1 | 가라앉은 감옥 | 절차 생성 맵. 구울·여간수·궁수·폭탄마 + 변종, **중간 보스 1명**(수녀원장 / 거미 여왕 중 시드로 결정) |
| 2 | 통로 | 연금술사 모르웬(셀로 영구 강화 구매), 회복 샘 |
| 3 | 달빛 성벽 | 절차 생성 맵. 창기병·하피 등 + 변종, **중간 보스 1명**(발키리 기사단장 / 달의 마녀 중 시드로 결정) |
| 4 | 통로 | 위와 동일 |
| 5 | 사슬의 종탑 | 보스 「강철 여교도관」 (2페이즈) |

사망하면 1번부터 새 시드로 다시 시작합니다. 통로에서 쓰지 않은 셀은 사망 시 사라집니다.

## 적 (30종)
기본 6종 + 변종 24종(변종마다 전용 스프라이트 시트와 행동 변화가 있음). 변종은 진행도(깊이)가 깊어질수록 더 자주,
"후반" 표시가 붙은 것은 레벨 40% 지점부터 나옵니다. 정예(elite)는 능력치·오라만 강화되고 크기는 그대로입니다.
감옥 = 가라앉은 감옥, 성벽 = 달빛 성벽.

**구울 (감옥 중심 · 근접)**
- 구울 — 기본 근접 적
- 역병 구울 — 느리다. 죽으면 독구름(반경 40px, 3초, 초당 4)을 남김. 감옥
- 광란 구울 — 빠르고 2연타, 체력 70%. 감옥 후반·성벽
- 족쇄 구울 — 쇠사슬 철퇴 휘두르기(사거리 ×1.7, 피해 ×1.4, 강한 넉백). 감옥
- 망령 구울 — 플레이어 뒤로 순간이동(90px 이내)해 공격, 넉백 무시, 체력 80%. 감옥 후반·성벽

**여간수 (방패 근접)**
- 여간수 — 기본. 정면 방패로 막음
- 수석 간수 — 메이스 내려찍기가 바닥 충격파(점프로 회피)를 보냄. 감옥 후반·성벽
- 횃불 간수 — 공격에 점화(3초 화상), 횃불 빛을 들고 다님. 감옥
- 창 간수 — 창 찌르기(사거리 ×1.6). 감옥·성벽
- 사슬 간수 — 사슬 갈고리(180px)로 플레이어를 끌어당긴 뒤 강타, 방패 없음. 감옥 후반·성벽

**궁수 (원거리)**
- 궁수 — 기본 화살
- 화염 궁수 — 불화살(3초 화상). 감옥·성벽
- 연사 궁수 — 3발 부채꼴(±12°) 사격. 성벽
- 석궁수 — 1.2초 조준 후 관통 볼트(피해 ×1.8, 반사 불가). 감옥 후반·성벽
- 그림자 궁수 — 가까워지면 120px 이내로 블링크해 도망. 성벽

**폭탄마 (투척 · 자폭)**
- 폭탄마 — 기본 폭탄 투척
- 서리 폭탄마 — 폭탄이 2초간 빙결(피해 ×0.6). 성벽
- 집속 폭탄마 — 폭탄이 착지하면 3개로 분열. 성벽
- 자폭병 — 속도 ×1.8로 달려와 자폭(반경 50px, 방어 불가, 피해 ×1.5). 감옥 후반·성벽
- 독약사 — 독 플라스크가 산성 웅덩이(2.5초)를 남김. 감옥

**하피 (비행)**
- 하피 — 기본 급강하
- 폭풍 하피 — 급강하 대신 깃털 3발 사격. 성벽
- 까마귀 하피 — 급강하 ×1.4 빠르고 예비동작이 짧음. 성벽
- 세이렌 — 노래 파동(퍼지는 고리)에 맞으면 2초간 이동 −40%. 급강하와 번갈아 사용. 성벽
- 불꽃 하피 — 급강하 착지점에 2초간 불길이 남음. 감옥 후반·성벽

**창기병 (성벽)**
- 창기병 — 기본 돌진 찌르기
- 미늘창 기사 — 돌진 없이 넓은 2연타 휘두르기(사거리 약 70px). 성벽
- 성기사 — 정면 방패로 막으면서도 돌진. 성벽
- 결투가 — 3연속 찌르기, 공격 직후 첫 타격을 쳐냄(패링). 성벽
- 용기병 — 돌진 대신 플레이어 위치로 도약해 광역 착지. 성벽

## 중간 보스 (4명)
바이옴마다 한 명이 주 경로의 전용 방에 나옵니다(시드로 둘 중 선택). 접근하면 이름 카드와 중간 보스 체력바가 뜨고,
모든 공격은 예비동작(자세·번쩍임·바닥 표시) 뒤에 들어옵니다. 넉백 없음, 패링·기절만 잠깐 끊을 수 있습니다.
체력 약 650(감옥) / 900(성벽) × 난이도 보정.
**처치 보상(공통)**: 무기 1개 + 스킬 1개(티어 +1, 접사 보장) + 셀 10–15 + 골드 60–100.

| 이름 | 바이옴 | 공격 |
|---|---|---|
| 처형인 수녀원장 | 감옥 | 내려찍기(바닥 균열 선), 회전 칼날 돌진, 종을 울려 구울 2마리 소환 |
| 거미 여왕 | 감옥 | 거미줄 덩이(맞으면 1.2초 속박), 플레이어 위치로 도약(그림자 표시), 짧은 물기 돌진 |
| 발키리 기사단장 | 성벽 | 대검 2연 베기, 날아올라 표시된 선을 따라 급강하, 바닥을 훑는 검기 |
| 달의 마녀 | 성벽 | 유도 구체 3개, 순간이동(블링크), 표시된 자리에 떨어지는 달 파편 |

## 조작
**설정 > 조작**(타이틀 우상단 `설정` 버튼, 또는 일시정지 메뉴의 `설정`)에서 세 가지 방식 중 고를 수 있습니다.
어느 방식이든 **키보드는 항상 함께 동작**하고, **게임패드는 연결되어 있으면 방식과 관계없이** 입력을 받습니다.

### 1. 터치 제스처 (기본, 버튼 UI 최소화)
| 입력 | 동작 |
|---|---|
| 화면 왼쪽 드래그 | 이동 (손가락 위치에 투명 조이스틱) |
| 오른쪽 탭 | 주무기 공격 (연타 시 콤보) |
| 오른쪽 위로 스와이프 | 점프 (공중에서 한 번 더: 2단 점프, 길게 유지 시 최대 높이) |
| 오른쪽 좌/우 스와이프 | 구르기 (무적, 적 통과) |
| 오른쪽 아래로 스와이프 | 공중: 내려찍기 / 발판 위: 아래로 내려가기 |
| 오른쪽 길게 누르기 | 보조 무기 (활 조준·발사, 방패 막기·패링) |
| 좌상단 플라스크 아이콘 | 회복 |
| 우하단 스킬 아이콘 | 스킬 1/2 |
| 오브젝트 위 말풍선 탭 | 상호작용 (상자, 아이템, 문, NPC) |
| 우상단 미니맵 탭 | 전체 지도 |

### 2. 가상 버튼
화면 왼쪽에 방향키(← → ↓, 손가락을 밀어 방향 전환), 오른쪽에 `공격` `점프`(누르고 있으면 높이 점프)
`구르기`(누르고 있는 방향, 없으면 바라보는 방향) `보조`(누르고 있는 동안 활 조준·방패)와 장착한 스킬 버튼(아이콘 + 쿨다운)이 표시됩니다.
손가락마다 처음 누른 버튼을 따라가므로 **→ + 점프 + 공격을 동시에** 누를 수 있습니다.
`버튼 크기`(작게/보통/크게)와 `투명도`(연하게/보통/진하게)를 바꿀 수 있고, HUD(체력·미니맵·무기 아이콘)와 겹치지 않게 배치됩니다.
플라스크, 상호작용 말풍선, 미니맵, 일시정지는 그대로 화면을 터치합니다. 이 모드에서는 제스처 인식이 꺼집니다.

### 3. 게임패드 (Gamepad API, 표준 배치 / Xbox 이름)
패드를 연결하고 아무 버튼이나 누르면 `게임패드 연결됨: <이름>`이 표시됩니다. 설정에서 이 모드를 고르면 터치 컨트롤·힌트가 숨겨지고
연결된 패드 이름과 상태(`연결됨` / `게임패드를 연결하고 아무 버튼이나 누르세요`)가 보입니다.

| 동작 | 기본 버튼 | 동작 | 기본 버튼 |
|---|---|---|---|
| 점프 (길게 = 높이) | A | 상호작용 | RB |
| 구르기 | B | 스킬 1 | LT |
| 공격 | X | 스킬 2 | RT |
| 보조 무기 | Y | 지도 | Back(뒤로) |
| 회복 | LB | 일시정지 | Start(시작) |

이동은 왼쪽 스틱(데드존 0.25) 또는 십자키, 스틱/십자키 아래는 `아래`(내려찍기 · 발판 내려가기)입니다.
**모든 메뉴**(타이틀, 일시정지, 설정, 선택창, 연금술사, 지도, 사망/승리 화면)는 십자키/스틱으로 이동, **A 확인, B 뒤로**로 조작합니다
(메뉴에서는 매핑과 관계없이 항상 물리 A/B 버튼).
**버튼 매핑 변경**: 설정 > 조작 > 게임패드에서 동작을 고르고(`버튼을 누르세요…`) 원하는 버튼을 누르면 할당됩니다.
이미 쓰는 버튼이면 두 동작이 서로 교체되고, `기본값 복원`으로 되돌릴 수 있습니다.

### 키보드 (항상 사용 가능)
A/D 이동, W·Space 점프, J 공격, K 보조, L·Shift 구르기, S 아래, Q/E 스킬, R 회복, F 상호작용, M 지도, Esc 일시정지.
메뉴: 방향키/WASD 이동, Enter·J·Space 확인, Esc 뒤로. 타이틀에서 Esc = 설정.

## 설정
`설정`은 **조작 / 그래픽 / 사운드** 탭으로 나뉘며, 터치·키보드·게임패드로 조작합니다. 바꾼 값은 **즉시 적용되고 자동 저장**됩니다.
조작 탭에는 선택한 방식의 미리보기(제스처 애니메이션 / 버튼 배치 / 패드 매핑 표)가 나옵니다.

### 그래픽
| 항목 | 선택지 |
|---|---|
| 필터 | **선명(픽셀)** (기본) · **부드럽게** (쌍선형 확대) · **CRT** (주사선 + 비네팅 + 약한 RGB 마스크/잔광) · **LCD** (픽셀 격자) · **선명한 색감** (채도·대비↑) · **흑백** |
| 해상도 | 월드 버퍼 높이 **288**(가까이) / **360**(기본) / **432**(넓게 보임). HUD·글자 크기는 해상도와 무관하게 그대로 |
| 화면 맞춤 | **화면 채우기** (기본) · **정수 배율** (픽셀 단위 정확한 배율 + 검은 여백) |
| 화질 | **고화질** (devicePixelRatio 최대 2) · **절전** (DPR 1, 배터리·성능) |

필터는 게임 화면(월드)에만 적용되고 HUD·메뉴 글자는 항상 선명하게 위 레이어에 그려집니다. 색 필터는 CSS `filter`라 iOS Safari에서도 동작합니다.

## QA용 URL 플래그
`?seed=123`(시드 고정) · `?level=passage|ramparts|boss`(해당 레벨로 바로 이동) · `?god=1`(무적) · `?mute=1` · `?debug=2`(히트박스 표시)

브라우저 콘솔의 `window.__ds`: `start(seed)`, `gotoLevel('boss')`, `god()`, `teleport(x,y)`, `killAll()`, `give('spear', 0)`, `info()`,
`spawn('ghoul_plague')`(30종 아무 적이나 플레이어 앞에 소환), `gotoMiniboss()`(현재 레벨의 중간 보스 방 입구로 이동. 중간 보스가 있는 바이옴 레벨이 아니면 감옥 레벨을 먼저 로드하므로 몇 프레임 뒤 한 번 더 호출).

## 아트 파이프라인 (Blender)
모든 캐릭터·적·보스·NPC·소품·아이콘·타일·배경은 `tools/blender/*.py` 스크립트로 Blender에서 3D 모델링 →
툰 셰이딩 + 안티앨리어싱 없이 렌더 → `tools/pack/`에서 픽셀아트 후처리(하드 알파, 1px 외곽선) 후 스프라이트
시트로 패킹합니다. Dead Cells가 사용한 3D→픽셀 방식과 같습니다. 전체 재생성: `tools/build_assets.sh`
(Blender 4.x 필요). Higgsfield는 실행 환경에서 네트워크 접근이 차단되어 사용하지 않았습니다.

문서: `docs/DESIGN.md`(게임 디자인·에셋 규약), `docs/ARCHITECTURE.md`(코드 구조), `docs/TILES.md`(타일 렌더링 규약).

## 알려진 이슈
- `window.__ds` 디버그 훅과 `?god=1`이 배포 빌드에 포함되어 있음 (QA용, 정식 공개 전 제거 권장)
- 844×390 등 일부 해상도에서 비정수 배율 스케일링으로 픽셀 폭이 고르지 않음 (설정 > 그래픽 > 정수 배율로 해결, 단 DPR 3 기기에서는 캔버스가 DPR 2로 제한되어 완전한 픽셀 퍼펙트는 아님)
- 게임패드·가상 버튼은 실제 기기에서의 손맛(버튼 위치, 스틱 느낌, 진동 없음)을 자동 테스트로 확인할 수 없음 (가짜 `navigator.getGamepads`와 CDP 터치로만 검증)
