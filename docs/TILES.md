# TILES — terrain tilesets, back walls, parallax and the autotile contract

Owner: environment art + `LevelRenderer`. This file is the exact contract between
`tools/pack/post_tiles.py` (reference autotiler, writes the previews), the art
(`public/assets/tiles/*`, `public/assets/bg/*`) and `src/game/level/render.ts` (the game).
`tests/render.test.ts` runs the TypeScript implementation against `tests/render_golden.json`,
which is generated by the Python reference (`python3 tools/pack/post_tiles.py --golden`).
It refines DESIGN.md §8.3 (region format and a few extra lists are defined here).

Pipeline: `tools/blender/asset_tiles.py` and `asset_bg.py` render G-buffers (normals, depth,
object id, material id) of scripted 3D masonry into `build/env/`; `tools/pack/post_tiles.py` /
`post_bg.py` toon-shade them with per-biome palettes, paint the 2D details (moss, grass, drips,
cracks, sky, moon, clouds, fog, light shafts, embers), outline and pack them. `tools/build_assets.sh`
runs everything (`tools/build_assets.sh tiles bg` = only these two + post).
Preview of each biome: `build/preview/env_<biome>.png` (mock room built by the reference autotiler).

---------------------------------------------------------------------------
## 1. Inputs: tile ids and back-wall layer (TileMap)

| `map.tiles[i]` | meaning | art |
|---|---|---|
| 0 | empty | — |
| 1 | solid | autotiled terrain (fill + edge overlays) |
| 2 | one-way platform | platform piece (top 7 px of the cell is the walkable plank; top of cell = surface) |
| 3 | spikes | spike piece (hazard is the lower ~14 px of the cell) |
| 4 | breakable (secret) wall | breakable block art; **neighbours treat it as solid** |

| `map.bg[i]` | meaning |
|---|---|
| 1 `BG.Wall` (template `.`) | interior: back wall drawn (+ cracks, decoration, shadows) |
| 0 `BG.Sky` (template `,`) | open: nothing drawn, the parallax background shows through |

Rules of thumb for level authors: terrain thickness >= 4 tiles gets the dark "deep" masonry tiers (§4);
use `,` for windows/openings onto the far background; a vertical open span of 3–14 tiles between floor and
ceiling, 2 columns wide, may receive a pillar (§6). **Tower:** its back wall is a louvred belfry
screen with transparent arched openings — the bell-tower parallax shows through even where `bg == Wall`.

"solid-like" below = tile 1 or 4. **Out of bounds counts as solid-like** (tile 1, bg wall).
"open" = not solid-like (empty, platform, spikes).

## 2. Atlas JSON — `public/assets/tiles/<biome>.json` + `<biome>.png`

All sizes in px; the cell is 24 px. A **region** is `[sx, sy, sw, sh, ox, oy]`: source rect in the
PNG and the offset at which to draw it relative to the cell's top-left (overlays have a 12 px pad,
`ox = oy = -12`, so they can overhang the cell; the top lips are 24 x 36 with `oy = -12`).
Draw with `drawImage(img, sx, sy, sw, sh, cellX + ox, cellY + oy, sw, sh)`.

```jsonc
{ "biome":"prison", "tile":24, "pad":12, "image":"prison.png",
  "fill":     [32 regions], "fillMid":[32], "fillDeep":[32],   // seamless 8x4 macro, row-major; 24x24, ox=oy=0
  "backwall": [32],                                            // seamless 8x4 macro of the back wall
  "backCrack":[6],                                             // 24x24 overlays (cracks, moss, missing brick, damp)
  "top":[8], "topMoss":[8],                                    // lit top lips (plain / mossy-grassy), 24x36, oy=-12
  "topDeco":[6], "drip":[4],                                   // clutter on top of a lip / hanging moss under a ceiling (48x48 slots)
  "bottom":[8], "left":[4], "right":[4],                       // underside stones / left + right quoin columns (48x48 slots)
  "outer":{"tl","tr","bl","br"}, "inner":{"tl","tr","bl","br"},// single regions (48x48 slots)
  "platform":{"l","m":[3],"r","single"},
  "spikes":{"up":[3],"down","left","right"},                   // 40x40 slots (pad 8)
  "breakable":[2],                                             // 24x24, opaque
  "backdeco":{ "arch","window","chain","special","niche","special2","slit",   // regions (see sizes)
               "pillar":{"bot","mid","top"},
               "size":{"arch":[3,4],"window":[2,2],"chain":[1,3],"special":[2,3],"niche":[1,1],"special2":[2,2],"slit":[1,2]},  // cells (w,h)
               "chance":{ "arch":..., ...}, "pillar_chance":0.10 },
  "cfg":{"moss_chance","deco_chance","drip_chance","crack_chance","shadow_a","shadow_w":[top,side,bottom]},
  "colors":{"sky","solid","lip","back","deep","shadow","glow"} } // flat-colour fallback + shadow colour
```

`backdeco` pieces per biome (same names, different art): `arch` 3x4 (prison: barred gate arch; others: open arch),
`window` 2x2 (barred / lit window), `chain` 1x3 (hangs from a ceiling), `special` 2x3 (prison: barred cell door;
ramparts: banner; tower: bell bracket with a bell), `niche` 1x1 (skull / urn / ember vent), `special2` 2x2
(prison: hanging shackles; ramparts: heraldic shield; tower: cog), `slit` 1x2 (arrow slit / glowing vent),
`pillar` 2 wide, three 2x1 segments.

## 3. Variant hashing

Every random choice is a pure function of the cell, so a chunk can be rebuilt at any time and the
Python previews equal the game:

```
hash01(x, y, s) -> [0,1)            (all arithmetic is 32-bit unsigned, ints may be negative)
  h = imul(x,374761393) + imul(y,668265263) + imul(s,2246822519)        (mod 2^32)
  h = imul(h ^ (h >>> 13), 1274126177);  h ^= h >>> 16;  return h / 2^32
pick(list, r) = list[min(len-1, floor(r * len))]
```
Salts `s` (cell = (x,y), unless noted): 2 bottom, 3 left, 4 right, 5 moss-vs-plain (uses `(x>>1, y)`: moss comes
in 2-cell runs), 6 topMoss variant, 7 top variant, 8 topDeco chance, 9 topDeco variant, 10 drip chance,
11 backCrack chance, 12 pillar chance, 13 floor-anchored deco, 14 wall deco, 15 backCrack variant,
16 drip variant, 17 platform middle variant, 18 spike up variant, 31 breakable variant.

## 4. Terrain drawing (what `drawTiles` produces)

Draw order — **passes over the whole visible area, each in raster order (y, then x)**:

1. **fill** — for tile 1: pick the macro by depth tier `d` (Chebyshev distance to the nearest open cell,
   capped at 3): `d=1 -> fill`, `d=2 -> fillMid`, `d>=3 -> fillDeep` (progressively darker, dithered tint),
   cell `[(y & 3) * 8 + (x & 7)]` (the 8x4 macro is seamless in both directions, so stone courses run across cells).
   For tile 4: `breakable[pick(hash01(x,y,31))]` instead.
2. **edge** — for each tile-1 cell, with `N,S,W,E` = the 4 neighbours are *open*:
   1. `S`: `bottom[pick(h(x,y,2))]`
   2. `W`: `left[pick(h(x,y,3))]`;  `E`: `right[pick(h(x,y,4))]`
   3. `N`: lip = `topMoss[pick(h(x,y,6))]` if `h(x>>1,y,5) < cfg.moss_chance` else `top[pick(h(x,y,7))]`
   4. outer corners (on top of 1–3): `N&W -> outer.tl`, `N&E -> outer.tr`, `S&W -> outer.bl`, `S&E -> outer.br`
   5. inner (concave) corners: when both orthogonal neighbours are solid but the diagonal is open:
      `!N && !W && open(x-1,y-1) -> inner.tl`, `!N && !E && open(x+1,y-1) -> inner.tr`,
      `!S && !W && open(x-1,y+1) -> inner.bl`, `!S && !E && open(x+1,y+1) -> inner.br`.
3. **detail** — tile-1 cells: if `N` open and `h(x,y,8) < cfg.deco_chance` -> `topDeco[pick(h(x,y,9))]`;
   if `S` open and `h(x,y,10) < cfg.drip_chance` -> `drip[pick(h(x,y,16))]`.
4. **prop** — platforms and spikes:
   * platform (tile 2): `lc` = left neighbour is platform **or solid-like**, `rc` likewise on the right.
     `!lc && !rc -> single`, `!lc -> l`, `!rc -> r`, otherwise `m[pick(h(x,y,17))]`.
   * spikes (tile 3), first match wins: solid-like below -> `up[pick(h(x,y,18))]`; solid above -> `down`;
     solid left -> `right` (spikes grow out of the left wall); solid right -> `left`; else `up[...]`.

Overlays overhang the cell by up to 12 px (never more) into open neighbours, so chunk canvases carry a 12 px pad.

---------------------------------------------------------------------------
## 5. Back wall (what `drawBack` draws after the parallax)

For every cell with `bg == 1` and tile not solid-like (platforms/spikes/empty), in this order:

1. `backwall[(y & 3) * 8 + (x & 7)]`; plus, if `h(x,y,11) < cfg.crack_chance`, `backCrack[pick(h(x,y,15))]`.
2. decoration plan (§6), in plan order.
3. ambient shadow strips cast by solid-like neighbours onto the wall cell, colour `colors.shadow`,
   alpha ramp `a(i) = shadow_a * (1 - (i + 0.5)/n)^1.6` (i = px distance from the solid edge, n = strip length):
   solid above -> top strip `shadow_w[0]` px tall (10); solid left / right -> side strips `shadow_w[1]` (6) wide;
   solid below -> bottom strip `shadow_w[2]` (3) tall.

---------------------------------------------------------------------------
## 6. Back decoration plan (`plan_decor`, deterministic, whole map, computed once per level)

`free(x,y)` = in bounds, tile 0, `bg == 1`, not yet occupied. Three raster passes (y then x); placed pieces mark occupancy.

1. **Pillars** (2 wide). At `(x,y)` with solid-like cells above both columns and `free` at `(x..x+1, y)`:
   `L` = number of consecutive rows free in both columns; if `3 <= L <= 14`, both cells below the run are
   solid-like and `h(x,y,12) < backdeco.pillar_chance`: segments `pillar.top` at `y`, `pillar.mid` for
   `y+1 .. y+L-2`, `pillar.bot` at `y+L-1`; mark the 2 x L area.
2. **Floor-anchored** (`free(x,y)` and solid-like at `(x,y+1)`): `r = h(x,y,13)`; try `arch` for
   `r in [0, c_arch)`, then `special` for `r in [c_arch, c_arch + c_special)` (`c_* = backdeco.chance`);
   the footprint `size` (w x h) has its bottom-left at `(x,y)` and must be entirely `free`.
3. **Wall pieces** (top-left at `(x,y)`, `free(x,y)`): `r = h(x,y,14)`, ranges in order
   `window, slit, niche, special2, chain` each of width `chance[name]`; footprint must be free;
   `chain` additionally needs solid-like at `(x,y-1)` (it hangs from the ceiling).
   If the range matches but the footprint does not fit, nothing is placed at that cell.

## 7. Parallax — `public/assets/bg/<biome>.json`

```json
{ "sky":"#050a10",
  "layers":[ {"image":"prison_0.png","parallax":0.05,"y":0,"vpar":0.05,"repeatX":true}, ... ] }
```
Layers are listed **far -> near**, 1024 x 512 px, horizontally seamless; layer 0 is opaque (the others have
alpha), `sky` is the fallback fill. Drawn in screen space in `drawBack` before the back walls
(they are therefore only visible through `bg == Sky` cells and, in the tower, the belfry openings).

```
viewX, viewY = camera.viewX, camera.viewY (integers, include shake);  viewH = camera.h (360)
horizontal:  sx = floor(viewX * parallax);  first copy at x0 = -(sx mod W),  repeat every W while x < screenW
vertical  :  maxY  = max(0, levelPxH - viewH)
             slide = min(max(0, H - viewH), max(0, (maxY - viewY) * vpar))
             y     = round(viewH - H + slide + layer.y)         // bottom-anchored, never uncovers the screen
```
So at the lowest camera position the bottom 360 px of every layer are shown (horizon, fog, furnace glow at the
bottom, the moon/high architecture higher up) and layers slide down as the camera climbs, at `vpar` x the camera
movement, until the top edge is reached. `repeatX:false` draws a single copy at `-floor(viewX*parallax)`.

| biome | layers (far -> near), parallax |
|---|---|
| prison | 0 far arcade hall with teal glow (0.05) · 1 pillars, arches, chains, light shafts (0.16) · 2 cell-block with barred cells + fog (0.36) · 3 foreground pillars/chains silhouettes (0.62) |
| ramparts | 0 night sky, stars, big moon (0.01) · 1 clouds (0.05) · 2 mountains + distant castle with lit windows (0.16) · 3 near battlements, towers, banners (0.42) |
| tower | 0 hollow tower, louvre vents, furnace glow (0.04) · 1 timber trusses + far bells, embers (0.16) · 2 great bells, gears (0.38) · 3 foreground chains/beams (0.66) |

## 8. Renderer behaviour (`src/game/level/render.ts`)

* `drawBack(ctx, cam)`: sky fill, parallax layers (`world.assets.json.get('bg/<biome>.json')`, `layers[].img` loaded
  by the asset loader), then the pre-rendered back-wall chunk canvases (no pad, 768 x 432).
* `drawTiles(ctx, cam)` (ctx translated by `-cam.viewX/Y`): terrain chunk canvases (768+24 x 432+24, origin at the
  chunk origin minus 12 px) — static terrain is never drawn cell by cell at runtime.
* `drawFront(ctx, cam)`: intentionally empty — darkness, vignette and coloured light are done by `world.lights`
  (`src/game/fx/lighting.ts`, multiply by a per-biome ambient). The art is therefore authored a little brighter than
  it should look in play (gamma lift in `post_tiles.py`); `build/preview/env_<biome>_lit.png` approximates the final look.
* Chunks are 32 x 18 tiles (`CHUNK_W/H`), created lazily for visible chunks, LRU-capped (16 per kind). When
  `map.version` changes a chunk is rebuilt only if the checksum of its tiles (+3 cell margin) changed.
  The decoration plan is computed once (breaking a wall does not move decoration).
* Missing tileset / bg: flat colours per biome (`colors`), never throws.

Biome look: **prison** wet teal-grey stone, sickly mint lit lips, moss + slime drips, iron bars, teal light;
**ramparts** pale lavender moonlit stone, bright lips with grass fringe + ivy, purple night, banners;
**tower** dark red brick, orange-hot lips, iron truss walkways, belfry screen, bells and cogs in orange glow.
